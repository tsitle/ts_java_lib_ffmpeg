# Change Log

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](http://keepachangelog.com/)
and this project adheres to [Semantic Versioning](http://semver.org/).

## [1.2.3] - 2026-11-03

### Added

- FfmpegHelperFfLibVersion class for retrieving the FFmpeg version directly from the FFmpeg shared library
- support for more RKMPP hardware accelerated video encoders (for Rockchip CPUs) 
- more Unit Tests

### Fixed

- fix settings for MJPEG video encoder when not using RTP-compatible output mode

## [1.2.2] - 2026-11-01

First release after taking this library out of the [Java RTSP Server](https://github.com/tsitle/ts_rtsp_server/) project.
